# Concise review guide

The principal correctness risks are source definition drift, administrative double counting, false zero interpretation, incomplete API pagination, selected-unit normalization and weight-dependent eligibility. These are handled with verified pinned metadata, complete-municipality scope, raw value/attribute preservation, finite complete-page checks, immutable snapshot-scoped definitions, fixed regional cohorts and explicit nulls.

Seven official source indicators and three derived metrics cover 169 municipalities in 2023–2025. The two score components intentionally represent distinct capacity and demographic aspects. All source observations are admissible in the committed snapshot; a separate fictional missing-data UI example cannot enter official results.

Review the source evidence and hashes in data/sample, source-discovery.md, methodology.md, analytical contracts and PostgreSQL integration tests. Export JSON contains snapshot identity, exact cohort, definitions, weights and methodology. Findings are generated by the report CLI. Runtime, Docker, clean-clone, browser and CI evidence are recorded in verification-results.json and implementation-status.md.

Limitations: the score is demonstrative and relative; it cannot measure unmet demand, household access or investment returns. User prices, queues and cross-municipal journeys are outside the data. Automated agent review is separate from human acceptance.
